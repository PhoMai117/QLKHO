Phương án 2: Dạng danh sách tuần tự (Continuous Rows) – Phù hợp nếu dùng máy in tem cuộn nhiệt (máy in mã vạch mini)
Cách hoạt động: Dùng cho các xưởng dùng máy in tem chuyên dụng (như Xprinter, Godex, TSC) in trên cuộn decal nhiệt cắt rời từng tem.

Ưu điểm: Xuất ra file Excel hoặc PDF dạng các dòng liên tiếp, máy in cứ thế chạy đúng số lượng tem rồi cắt giấy tự động.
